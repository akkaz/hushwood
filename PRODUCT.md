# Hushwood
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Delegated explicitly by user for autonomous one-prompt build. React + Vite frontend, Cloudflare Worker hosted by ChatGPT Sites, managed D1 database and Sites identity.
## Users
Teachers project a classroom sound game on a whiteboard. School coordinators manage classes and shared competitions. No student accounts or names.
## Purpose
Turn classroom quiet time into collective creature growth, XP, streaks and configurable rewards. Public anonymous demo; authenticated persistent school mode.
## Constraints
English default; Italian French German Spanish Portuguese included. Microphone processed locally; never upload audio. Separate demo from real scored sessions. New original implementation for Ten Prompt Build; prior Decibel idea is inspiration only. All decisions delegated; no followup questions.
## Success
Usable public demo, working authenticated school flow, reproducible open source, deployed verification, teaser and candid submission/history.
