# Hushwood build plan
New repository from empty directory. Original code and assets; prior Decibel is idea inspiration only. No copying prior project features.
1. Scaffold React TypeScript Vite app + Vercel Node API. Warm illustrated forest identity, original animated geometric creature presets, projector game, landing interactive demo, six locales.
2. Browser Web Audio measures relative RMS, calibration and adjustable threshold (not scientific dB). Timer accrues quiet seconds, streak XP, evolution, break grace, no negative lifetime XP. Pause/hidden/offline cleanup. Demo simulated and never submits rewards.
3. Mongo Atlas dedicated hushwood database if provisionable. Email/password scrypt accounts, HttpOnly same-site session cookie, origin checks, validation/rate limits. School creator owns school; teachers join using private invite token plus configured email domain (no false email verification claims). Classes persist XP. Server validates elapsed time, caps reward rates, atomic/idempotent lesson finish; tenant membership for every operation. No student data/audio. Cup ranked by quiet proportion with minimum duration and configurable date/prize; transparent not tamper-proof client measurement.
4. Dashboard create school/classes, invite teachers, configure cup/rewards, launch class, see aggregate results. Graceful unavailable DB rather than fake persisted success.
5. Tests for scoring/auth/tenant boundaries and end-to-end deployed Chrome. Vercel CLI deployment hushwood.akkaz.dev without touching apex. GitHub public repo after secret review. Teaser video and submission writeup with exact prompt/history and disclosures.
6. Astra final review (two rounds max, 45 min review/fix budget), orchestrator selects material fixes and useful improvements; verify. Cleanup our temporary assets/processes and record preserved work.
Contract: GET /api/state -> {user, schools, classes, lessons}; POST /api/auth {action:register|login|logout,email,password,name}; POST /api/schools {action:create|join|update, name, schoolId, inviteCode, domain, cup}; POST /api/classes {schoolId,name,mascot}; POST /api/lessons {action:start|finish,classId,lessonId,quietSeconds,measuredSeconds,bestStreak}. Backend worker may refine contract, communicate immediately. API errors {error}.

## Current architecture decision
User follow-up delegates choosing Sites hosting and DB. Adopt Sites Cloudflare Worker + D1 and platform ChatGPT identity; public anonymous demo, protected school membership, invitation plus optional verified identity email domain. Retain React/Vite source. Replace Mongo/Vercel-only backend. Use native Sites source publishing, explicit public audience as requested. No copied older features. All model/effort decisions delegated explicitly in attached brief: workers gpt-6.1-sol high; plan and final reviewer gpt-6-astra high. Audit plan before backend implementation. Remaining deliveries unchanged including Chrome, video, source and build history. Cleanup last.
- Public game supports actual microphone without account as well as clearly simulated landing demo. Anonymous sessions never call scoring writes.
- Domain matching is an optional organizational filter, not a claim of school/email verification. Secret invitations authorize school joining; owner manages rotation and membership.
- Auth uses Sites-injected identity only; no alternate password stack or trusted public headers outside Sites. Standalone hosting documents trusted proxy requirement; local test identity only with explicit local-only configuration.
- D1 migrations packaged under drizzle/; atomic conditional lesson finish, per-class active session lock, elapsed/counter caps. Rewards configurable by owners, student names never requested.
